# Solution 05 - Buckets de montants

## Ma facon de raisonner avec toi

La CTE que je construis calcule une etiquette par transaction avec un `CASE`.

L'agregation suivante compte et additionne chaque etiquette.

Le `CASE` de tri impose l'ordre business plutot que l'ordre alphabetique.

## Les pieges que je veux que tu surveilles

- Ecrire `amount <= 50` dans le bucket `small`, ce qui deplace la borne 50.
- Ecrire `amount < 200` pour `medium`, ce qui envoie la borne 200 dans
  `large`.
- Oublier le `GROUP BY` de l'expression calculee.
- Trier `large`, `medium`, `small` alphabetiquement.

Le jeu de donnees contient des transactions a exactement 50.00 et a exactement
200.00, alors les deux bornes sont verifiees pour vrai.

## Une autre facon que je te montrerais

L'expression `CASE` peut etre repetee directement dans le `SELECT` et le
`GROUP BY`, sans CTE.
