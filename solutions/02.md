# Solution 02 - Volume par succursale

## Ma facon de raisonner avec toi

Le `JOIN` ne conserve ici que les succursales qui ont au moins un compte
actif.

`COUNT(a.id)` compte les comptes apres le filtre de statut.

`HAVING` filtre le resultat de `COUNT`, alors que `WHERE` filtre les lignes
avant l'agregation.

## Les pieges que je veux que tu surveilles

- Mettre `COUNT(a.id) >= 20` dans `WHERE`.
- Oublier `b.name` dans le `GROUP BY`.
- Trier le texte du nom au lieu du volume demande.

## Une autre facon que je te montrerais

Un `LEFT JOIN` avec la condition de statut dans le `ON` permettrait aussi
d'afficher les succursales a zero, puis `HAVING COUNT(a.id) >= 20` garderait
le meme resultat final.
